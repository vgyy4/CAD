# ADR 0000: Project name — Gusset

- Status: accepted
- Date: 2026-10-10

## Context
The spec asks for a short, original name that is not close to existing CAD tools
(e.g. "OpenCAD" ≈ OpenSCAD) and does not imitate trademarks (e.g. "*360").

## Candidates checked (2026-10-10)
crates.io was checked through the registry API (`GET /api/v1/crates/<name>`, 404 = free).
For the names that were free there, the web and GitHub were then searched for software
products and trademarks.

| Candidate | crates.io | Web / GitHub collisions | Notes |
|---|---|---|---|
| kerf | taken | — | |
| dowel | taken | — | |
| tenon | taken | — | |
| knurl | taken | — | |
| arbor | taken | many software products | |
| sprue | taken | — | |
| trunnion | free | none found | long, hard to spell |
| cotter | free | not searched further | weak associations ("cotter pin" only) |
| gimlet | free | Oxide Computer's "Gimlet" server sled | collision risk |
| ogee | free | Eclipse Ogee (archived Java project) | minor collision |
| chamfr | free | none | reads as a typo; awkward to say |
| **gusset** | **free** | **none in software; the only trademark found is GUSSET BRAND for clothing (Diamond Gusset LLC, 2016)** | **chosen** |

## Decision
**Gusset.** A gusset is the plate that joins and strengthens structural members. That
fits a tool that joins the strengths of several CAD traditions, and it is a term
mechanical designers model all the time. It is short, easy to say and spell, has no
"CAD" suffix, and is not close to any existing CAD product name.

- Binary / CLI: `gusset` (`gusset build model.gus --export out.step`, `gusset mcp`).
- Crates: `gusset-*` (`gusset-doc`, `gusset-kernel`, ...).
- Native project extension: `.gus` (see the format ADR).

## Consequences
- The clothing trademark is in a different class (25 vs 9/42), so the risk is low.
  Re-check before any trademark filing.
- The repository is still named `CAD`. Renaming it is a repository-settings change,
  so it is left for the owner (noted in PROGRESS.md).
